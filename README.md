## 📌 Sobre o Projeto

Landing page estática desenvolvida com foco em **captura de leads e experiência visual moderna**.

Características principais:

- Interface limpa e profissional  
- Estrutura leve e sem dependências  
- Validação nativa de formulário  
- Design responsivo  

---

## 🛠️ Tecnologias

- HTML5  
- CSS3  

---

## 🎯 Funcionalidades

- ✔️ Campos obrigatórios com validação nativa   
- ✔️ Feedback visual de erro  
- ✔️ Layout responsivo  
- ✔️ Animações suaves  
- ✔️ UI moderna com gradientes e glassmorphism  

---

## 📂 Estrutura

📁 projeto/
├── index.html

## 🎨 Design System

- Uso de variáveis CSS (`:root`)
- Gradientes dinâmicos
- Efeitos de foco e hover
- Glassmorphism no card de formulário
- Animações com `@keyframes`
